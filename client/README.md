# Project name: Laz Chat (Frontend)

## Technologies

- Framework: React + Vite
- Language: Javascript
- Styling: TailwindCSS
- API architectural styles: RestAPI (`axios`) + Socket (`SignalR`)
- Authentication: Jwt + OAuth (pending)
- Testing: Vitest (pending)

## Features

- Sign in / Sign up
- Send / Receive message in realtime between group or individual (pending)
- View user profile (pending)

## Getting started

### Prerequisites

You need:

- Node.js version > 20

### Install dependencies

```bash
npm install
```

### Run the project in developer mode

```bash
npm run dev
```
